# Custom UI icons

Drop your own drawings here to replace temporary CDN icons.

Use these file names first:

- `dashboard.svg`
- `lab.svg`
- `projects.svg`
- `articles.svg`
- `tasks.svg`
- `pet.svg`
- `game.svg`
- `wall.svg`
- `notifications.svg`
- `coin.svg`
- `apple.svg`
- `heart.svg`
- `ball.svg`
- `party.svg`
- `crown.svg`
- `grad.svg`
- `flower.svg`
- `star.svg`
- `cat.svg`
- `dog.svg`
- `frog.svg`
- `axolotl.svg`
- `capybara.svg`

SVG is preferred. If an SVG is missing, the frontend tries the same name as
`.png`, then falls back to a temporary internet icon.
